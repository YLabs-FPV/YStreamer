Which output to use depends on what receives the video:

| Software                        | Output               | Guide                                                   |
| ------------------------------- | -------------------- | ------------------------------------------------------- |
| VLC, ffplay, ffmpeg             | RTSP (on by default) | [VLC and ffplay](/docs/other-software/vlc)              |
| OBS Studio                      | SRT, or RTSP         | [OBS Studio](/docs/other-software/obs)                  |
| QGroundControl, Mission Planner | UDP (RTP, port 5600) | [Ground stations](/docs/other-software/ground-stations) |
| YouTube, Twitch, Facebook       | RTMP                 | [Live platforms](/docs/other-software/live-platforms)   |

Each output's settings are described in [streaming](/docs/using/streaming).
