Start with [common issues](/docs/help/common-issues). If it isn't there:

1. Look at the **Logs** page in the web interface for an error, or run
   `ystreamer logs` over SSH.
2. Check the **Performance** page for a power warning.
3. [Open an issue on GitHub](https://github.com/YLabs-FPV/YStreamer/issues/new/choose),
   or use **Report an issue** under **System → About**.
   Include your goggles or camera, how you installed YStreamer, the version
   from **System → About**, and the lines from the **Logs** page.
