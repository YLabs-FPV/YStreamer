---
title: Network and access
description: Getting the device on a network, reaching it from anywhere, and locking it down.
order: 20
---

The device can run its own Wi-Fi network, join yours, use Ethernet, or share a
phone's connection over USB. If it can't be reached, it brings its own network
back so you can always get in.

Once it's on a network, set a password for the web interface. To reach it from
outside your network, use Tailscale or WireGuard.
