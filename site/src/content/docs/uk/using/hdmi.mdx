Підключи екран до одного з портів micro-HDMI на Pi; YStreamer використовує
перший порт, до якого під'єднано екран. Налаштування — у **Display → HDMI**.

| Налаштування       | Що робить                                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Show video on HDMI | Вимикай, коли нічого не підключено: це звільняє декодер і частину процесора для трансляцій.                                  |
| Resolution         | **Automatic** обирає найчіткіший режим до 1080p, якомога ближчий до 60 Гц, який підтримує екран. Або обери режим екрана сам. |
| Scaling            | **Fit** показує всю картинку, зі смугами, якщо пропорції різні. **Fill** заповнює екран і обрізає краї.                      |
| Rotate 180°        | Для екрана, встановленого догори дриґом.                                                                                     |
| Mirror             | Віддзеркалює картинку зліва направо.                                                                                         |

У списку роздільностей позначено режим, якому надає перевагу сам екран, і
режими, у яких картинка буде розтягнута.

Поки відео немає, HDMI показує [заставку](/docs/using/splash-and-logo).
