## Будова

На бічній панелі є всі сторінки:

| Група       | Сторінки                                             |
| ----------- | ---------------------------------------------------- |
|             | **Watch**: перегляд наживо                           |
| Video       | **Input**, **Streaming**, **Recording**, **Display** |
| Device      | **Network**, **System**                              |
| Diagnostics | **Performance**, **Logs**                            |

На телефоні бічна панель згортається в меню.

## Збереження налаштувань

Зміни на сторінці налаштувань не застосовуються, доки ти не натиснеш
**Save**. **Discard** скасовує їх. Бічна панель позначає сторінки з
незбереженими змінами.

Налаштування, які можуть відрізати тебе від пристрою, наприклад інший режим
Wi-Fi, спершу просять підтвердження.

## Сторінка Watch

Відео наживо, а також:

- **Stats**: бітрейт відео та буфер плеєра.
- **Reconnect**: перезапускає плеєр.
- **Recorder**: запуск і зупинка запису на пристрої, відкриття файлів.
- **Camera**: налаштування камери повітряного модуля, з окулярами DJI. Див.
  [налаштування камери](/docs/using/camera-settings).
- Власний запис повітряного модуля: чи йде запис і на яку карту.
- **Telemetry**: батарея, GPS, висота, швидкість і шлях додому апарата, з
  окулярами DJI. Див. [телеметрію](#телеметрія).

### Телеметрія

З окулярами DJI панель **Telemetry** показує дані, які апарат надсилає через
лінк, ті самі, що показують окуляри:

| Поле     | Показує                                                                     |
| -------- | --------------------------------------------------------------------------- |
| Battery  | Батарею апарата                                                             |
| Altitude | Висоту над точкою зльоту                                                    |
| Vertical | Швидкість набору (↑) або зниження (↓)                                       |
| Speed    | Швидкість відносно землі                                                    |
| GPS      | Супутники або рівень GPS від 0 до 5; **No fix**, доки апарат не має позиції |
| Home     | Відстань і напрямок до точки дому                                           |

Стрілка вказує додому відносно того, куди дивиться апарат, тож угору означає
прямо вперед. Сторона світу та градуси поруч рахуються від півночі.

Панель з'являється лише тоді, коли апарат надсилає дані. Значення, яке не
приходило кілька секунд, стає порожнім (—), а не лишається старим. Глядачі
без входу теж бачать панель, але ніколи не бачать, де апарат.

<Admonition type="note">
  Які дані приходять, залежить від повітряного модуля. Їх розібрали на Avata 2 з
  Goggles 3; інші модулі можуть залишити деякі порожніми.
</Admonition>

#### Для наземних станцій

`GET /api/telemetry` повертає ті самі дані в JSON, а також координати апарата
й точки дому. Опитувати до 5 разів на секунду більш ніж достатньо. Те, чого
апарат останнім часом не надсилав, має значення `null`, ніколи не `0`. Якщо
встановлено пароль, запиту потрібна сесія з входом, як і решті API.

```json
{
  "battery_percent": 81,
  "gps_fix": true,
  "satellites": 17,
  "gps_level": null,
  "lat": 45.000912,
  "lon": 7.000134,
  "altitude_m": 21.5,
  "vertical_speed_mps": -0.5,
  "horizontal_speed_mps": 4.2,
  "pitch_deg": 1.3,
  "roll_deg": -1.2,
  "yaw_deg": -113.9,
  "home_set": true,
  "home_lat": 45.0,
  "home_lon": 7.0,
  "home_altitude_m": 240.3,
  "home_distance_m": 102.0,
  "home_bearing_deg": 185.9,
  "rc_signal": 4,
  "vtx_signal": null
}
```

`vertical_speed_mps` додатна під час набору висоти. `home_altitude_m` це
висота точки дому за GPS, а не висота над нею. `satellites` надсилають модулі
O4, `gps_level` ті, що надсилають рівень. Котре з `rc_signal` і `vtx_signal`
(від 0 до 5 поділок) є лінком пульта, а котре відео, ще не підтверджено.

### Гарячі клавіші

| Клавіша     | Дія                             |
| ----------- | ------------------------------- |
| `S`         | Показати або сховати статистику |
| `P`         | Картинка в картинці             |
| `T`         | Режим кінотеатру                |
| `F`         | Повний екран                    |
| `Shift`+`R` | Почати або зупинити запис       |

### WebRTC або WebSocket

Браузер отримує відео одним із двох способів, який обирається в
**Streaming → Browser**:

- **WebSocket** (за замовчуванням): стабільніша частота кадрів.
- **WebRTC**: найменша затримка.

**Viewer limit** обмежує, скільки браузерів можуть дивитися одночасно. Кожен
глядач навантажує процесор, тож обмеження зберігає плавність HDMI та RTSP.

## Тема

**System → General → Theme** перемикає світлу й темну тему. Вибір
запам'ятовується лише в цьому браузері.

## Часовий пояс

**System → General → Timezone** задає часовий пояс пристрою, який
використовується для дати й часу в назвах [записів](/docs/using/recording).
Образ починає з UTC. Поки так, картка пропонує одним натисканням часовий пояс
твого браузера, якщо тільки браузер теж не на UTC. Натисни **Save**, щоб
застосувати.
