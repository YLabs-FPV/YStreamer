## Будова

На бічній панелі є всі сторінки:

| Група       | Сторінки                                             |
| ----------- | ---------------------------------------------------- |
|             | **Watch**: перегляд наживо                           |
| Video       | **Input**, **Streaming**, **Recording**, **Display** |
| Device      | **Network**, **System**                              |
| Diagnostics | **Performance**, **Logs**                            |

На телефоні бічна панель згортається в меню.

## Збереження налаштувань

Зміни на сторінці налаштувань не застосовуються, доки ти не натиснеш
**Save**. **Discard** скасовує їх. Бічна панель позначає сторінки з
незбереженими змінами.

Налаштування, які можуть відрізати тебе від пристрою, наприклад інший режим
Wi-Fi, спершу просять підтвердження.

## Сторінка Watch

Відео наживо, а також:

- **Stats**: бітрейт відео та буфер плеєра.
- **Reconnect**: перезапускає плеєр.
- **Recorder**: запуск і зупинка запису на пристрої, відкриття файлів.
- **Camera**: налаштування камери повітряного модуля, з окулярами DJI. Див.
  [налаштування камери](/docs/using/camera-settings).
- Власний запис повітряного модуля: чи йде запис і на яку карту.

### Гарячі клавіші

| Клавіша     | Дія                             |
| ----------- | ------------------------------- |
| `S`         | Показати або сховати статистику |
| `P`         | Картинка в картинці             |
| `T`         | Режим кінотеатру                |
| `F`         | Повний екран                    |
| `Shift`+`R` | Почати або зупинити запис       |

### WebRTC або WebSocket

Браузер отримує відео одним із двох способів, який обирається в
**Streaming → Browser**:

- **WebSocket** (за замовчуванням): стабільніша частота кадрів.
- **WebRTC**: найменша затримка.

**Viewer limit** обмежує, скільки браузерів можуть дивитися одночасно. Кожен
глядач навантажує процесор, тож обмеження зберігає плавність HDMI та RTSP.

## Тема

**System → General → Theme** перемикає світлу й темну тему. Вибір
запам'ятовується лише в цьому браузері.

## Часовий пояс

**System → General → Timezone** задає часовий пояс пристрою, який
використовується для дати й часу в назвах [записів](/docs/using/recording).
Образ починає з UTC. Поки так, картка пропонує одним натисканням часовий пояс
твого браузера, якщо тільки браузер теж не на UTC. Натисни **Save**, щоб
застосувати.
