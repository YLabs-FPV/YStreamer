Кнопка або перемикач на роз'ємі GPIO на Pi може запускати й зупиняти
[запис](/docs/using/recording), а необов'язковий індикатор світиться, поки
йде запис.

## Підключення

- **Кнопка або перемикач**: між вибраним піном GPIO і будь-яким піном землі.
  Резистор не потрібен: використовується вбудована підтяжка Pi.
- **Індикатор (необов'язково)**: світлодіод від свого піна GPIO, через
  резистор приблизно на 330 Ом, до землі. Резистор можна ставити з будь-якого
  боку світлодіода, але сам світлодіод має стояти правильно: **довша ніжка
  (+)** — до піна GPIO, коротша — до землі. Якщо навпаки, він просто не
  світитиметься.

У цьому прикладі кнопка на GPIO17 (пін 11) із землею на піні 9, а індикатор
на GPIO18 (пін 12) із землею на піні 14.

## Налаштування

У **Recording → Settings → Record button**:

| Налаштування           | Що робить                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| Use a button or switch | Вмикає функцію.                                                                                  |
| Type                   | **Push button**: кожне натискання запускає або зупиняє. **Switch**: записує, поки він замкнений. |
| Pin                    | GPIO, до якого підключено кнопку. За замовчуванням GPIO17 (пін 11).                              |
| Recording light        | GPIO для індикатора або **No light**.                                                            |

Коли функцію ввімкнено, на картці написано **Listening**. Натисни кнопку або
перемкни перемикач, щоб побачити, що його зафіксовано.

Якщо **перемикач** уже замкнений під час увімкнення, наприклад після
вимкнення світла, запис почнеться знову сам.

<Admonition type="warning">
  Не використовуй пін 40 — це пін скидання: якщо тримати його замкненим на землю
  під час запуску Pi, налаштування скинуться.\ Див. [резервна копія та
  скидання](/docs/maintenance/backup-and-reset).
</Admonition>
