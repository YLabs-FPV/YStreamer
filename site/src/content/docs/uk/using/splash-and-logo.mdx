## Заставка

Поки відео немає, YStreamer надсилає замість нього заставку: на HDMI, у
браузери та в потоки. У записи вона не потрапляє.

За замовчуванням заставка показує, як дістатися до пристрою: його адреси, назву
й пароль точки доступу та QR-код для підключення.

У **Display → Splash screen**:

| Налаштування                         | Що робить                                                                  |
| ------------------------------------ | -------------------------------------------------------------------------- |
| Upload image                         | Твоє зображення замість стандартного. **Use default** повертає стандартне. |
| Image scaling                        | **Fit** або **Fill** для твого зображення.                                 |
| Show status over custom image        | Залишає адреси та стан з'єднання внизу.                                    |
| Show access point password on screen | Якщо вимкнено, пароль і QR-код не показуються.                             |
| Freeze on last frame                 | Коли відео зникає, залишає натомість останній кадр.                        |
| Grayscale frozen frame               | Показує застиглий кадр сірим, щоб його не сплутали з відео наживо.         |

<Admonition type="tip">
  У публічному місці вимкни **Show access point password on screen** або зміни
  пароль у **Network**.
</Admonition>

## Логотип

У **Display → Logo** перетягни зображення: PNG, WebP або JPEG, прозорість
зберігається. Потім перетягни його в потрібне місце на попередньому перегляді,
а за кут — зміни розмір, або скористайся повзунком **Size**. **Opacity** — від
10 до 100 %, а **Show logo** вмикає й вимикає логотип, не видаляючи його.

Де з'являється логотип, залежить від джерела:

- **Окуляри DJI**: лише на **HDMI** і в перегляді в браузері. Потоки й записи
  містять власне відео окулярів без змін.
- **USB-камера**: у самому відео, тобто на всіх виходах і в записах.
