На пристрої, через [SSH](/docs/network/security) або з підключеною
клавіатурою, команда `ystreamer` перевіряє сервіс і виправляє те, що могло б
відрізати тебе від вебінтерфейсу.

```sh
ystreamer help
```

| Команда                           | Що робить                                         |
| --------------------------------- | ------------------------------------------------- |
| `ystreamer status`                | Чи працює YStreamer і які адреси відкривати       |
| `ystreamer logs`                  | Останні 200 рядків журналу                        |
| `ystreamer logs -f`               | Останні 50 рядків, а потім стежить за новими      |
| `sudo ystreamer restart`          | Перезапускає YStreamer                            |
| `sudo ystreamer password`         | Встановлює пароль вебінтерфейсу                   |
| `sudo ystreamer password --clear` | Прибирає пароль вебінтерфейсу                     |
| `sudo ystreamer reset`            | Повертає всі налаштування й пароль до стандартних |
| `ystreamer version`               | Встановлена версія                                |

`restart`, `password` і `reset` потребують `sudo`.

## Стан

```sh
ystreamer status
```

```
YStreamer 0.1.0
Service:        running
Web interface:  http://ystreamer.local  http://192.168.1.50
Password:       run with sudo to see
```

Із `sudo` команда також показує, чи встановлено пароль. Якщо сервіс працює на
іншій версії, ніж встановлена, наприклад посеред оновлення, вона про це
скаже.

## Пароль

```sh
sudo ystreamer password
```

Двічі питає новий пароль, не показуючи його. Щонайменше 6 символів. Діє
одразу, і браузерам, які були в системі, доведеться увійти знову. `--clear`
натомість прибирає пароль.

Для скрипта передай пароль одним рядком:

```sh
echo 'new-password' | sudo ystreamer password
```

<Admonition type="tip" title="Не можеш увійти?">
  Це найшвидший спосіб розв'язати проблему забутого пароля, якщо до пристрою ще
  можна дістатися через SSH.
</Admonition>

## Скидання

```sh
sudo ystreamer reset
```

Повертає всі налаштування й пароль вебінтерфейсу до стандартних, спершу
запитавши; `--yes` пропускає запитання. YStreamer перезапускається зі
стандартними налаштуваннями, і мережеві налаштування теж повертаються до
них.

Записи, логотип і заставка зберігаються. Попередні налаштування зберігаються
як `settings.before-reset.json`. Інші способи скидання дивись у розділі
[резервна копія та скидання](/docs/maintenance/backup-and-reset).

## ystreamer run

`ystreamer run` — це сам YStreamer, програма, яку запускає системний сервіс.
Не запускай її вручну: використовуй `sudo ystreamer restart`. Сама по собі
команда `ystreamer` показує довідку.
