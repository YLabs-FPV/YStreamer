Якщо на твоїй Pi вже працює **Raspberry Pi OS Lite (64-біт, Debian 13
"Trixie")**, YStreamer можна додати однією командою.

<Admonition type="warning" title="Лише Lite">
  Якщо під час завантаження запускається робочий стіл, YStreamer не може
  показувати відео на HDMI. Використовуй Raspberry Pi OS Lite або вимкни робочий
  стіл через `sudo raspi-config` (System Options → Boot).
</Admonition>

## Запуск

На Pi, через SSH або з підключеною клавіатурою:

```sh
curl -fsSL https://ystreamer.yarosfpv.com/install.sh | sudo sh
```

Скрипт:

1. Перевіряє пристрій: 64-бітна система, Raspberry Pi 4, Trixie, порт 80
   вільний. На неперевіреному обладнанні спершу питає, чи продовжувати.
2. Завантажує останню версію й перевіряє її підпис.
3. Перелічує, що змінить, і питає перед встановленням.
4. Встановлює й запускає YStreamer, а потім показує адресу вебінтерфейсу:
   `http://<hostname>.local`.

## Що змінюється

- Встановлюється пакет `ystreamer` і все, що йому потрібно, наприклад
  GStreamer.
- YStreamer запускається одразу й під час кожного завантаження. Він
  використовує порт 80 і вихід HDMI.
- До `/boot/firmware/config.txt` додаються два рядки, а оригінал зберігається
  в копії: один налаштовує порт USB-C для окулярів, інший дає відеоапаратурі
  достатньо пам'яті.

<Admonition type="info" title="Перезавантаж один раз">
  Коли змінюються налаштування завантаження, перезавантаж Pi перед підключенням
  окулярів. Скрипт скаже, коли це потрібно.
</Admonition>

## Параметри

Параметри передаються після `sh -s --`:

| Параметр      | Що робить                                                           |
| ------------- | ------------------------------------------------------------------- |
| `--check`     | Перевіряє пристрій і завантаження. Нічого не встановлює.            |
| `--yes`, `-y` | Нічого не питає, окрім підтвердження повернення до старішої версії. |

Наприклад, щоб перевірити пристрій, нічого не змінюючи:

```sh
curl -fsSL https://ystreamer.yarosfpv.com/install.sh | sudo sh -s -- --check
```

## Повторний запуск

На Pi, де YStreamer уже є, скрипт перед запитанням каже, що встановлено і що
він зробить:

- **Старіша версія**: оновлює її до останньої.
- **Остання версія**: перевстановлює її.
- **Новіша версія**, ніж останній реліз: повертає до релізу, але лише після
  твого підтвердження в терміналі, навіть із `--yes`.

Налаштування, вхід і записи зберігаються. YStreamer перезапускається: відкритий
запис завершується, а потоки й HDMI призупиняються на кілька секунд. Версія,
що працювала, стає тією, до якої повертає
[Roll back](/docs/maintenance/updates#відкат).

`--check` скаже, що саме станеться, нічого не змінюючи.

## Відмінності від образу

- **Мережа**: YStreamer залишає Wi-Fi та Ethernet системі, доки ти не
  зміниш їх у вебінтерфейсі. Див. [Wi-Fi та Ethernet](/docs/network/wifi-and-ethernet).
- **SSH і обліковий запис** лишаються такими, як ти їх налаштував; керування
  SSH у вебінтерфейсі є лише в образі.
- **Адреса** використовує ім'я хоста твоєї Pi, а не `ystreamer`.

## Видалення

```sh
sudo apt remove ystreamer
```

Це прибирає налаштування завантаження; перезавантаж Pi, щоб повернути порт
USB-C. `sudo apt purge ystreamer` також видаляє налаштування й пароль
вебінтерфейсу. Записи в `/var/lib/ystreamer` зберігаються в обох випадках.
