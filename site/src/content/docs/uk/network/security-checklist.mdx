Від початку YStreamer налаштований так, щоб до нього було легко дістатися.
У твоїй власній мережі це нормально, але перш ніж брати його в спільне
місце — на захід, клубне поле чи у Wi-Fi закладу, — пройдися цим списком.

## Що відкрито за замовчуванням

| Що                  | Порт | За замовчуванням                                                    |
| ------------------- | ---- | ------------------------------------------------------------------- |
| Вебінтерфейс        | 80   | Без пароля: будь-хто, хто дістанеться, може змінювати налаштування  |
| Перегляд у браузері | 80   | Дивитися може будь-хто, навіть коли пароль встановлено              |
| RTSP                | 554  | Увімкнено, без пароля                                               |
| SRT                 | 9000 | Вимкнено; без шифрування, якщо немає парольної фрази                |
| Точка доступу       | -    | Увімкнена в новому образі, пароль `ystreamer`, видно на екрані HDMI |
| SSH (лише образ)    | 22   | Вимкнено; обліковий запис `ystreamer`, пароль `ystreamer`           |

RTMP і UDP лише надсилають відео назовні, тож нічого на пристрої не
відкривають.

## Чекліст

1. **Встанови пароль вебінтерфейсу** в **System → General → Access**. Без
   нього будь-хто в мережі може змінити будь-яке налаштування, зокрема Wi-Fi.
   Див. [пароль і SSH](/docs/network/security).
2. **Виріши, хто може дивитися.** Коли пароль встановлено, у браузері все
   одно можна дивитися без входу. Увімкни **Require password to watch**, якщо
   так не має бути.
3. **Дай RTSP власний пароль** або вимкни його. У **Streaming → RTSP**
   увімкни **Require password**. Пароль вебінтерфейсу не поширюється на RTSP,
   а сам пароль RTSP передається без шифрування.
4. **Використовуй парольну фразу для SRT** у **Streaming → SRT**, особливо
   через інтернет. Без неї відео передається незашифрованим.
5. **Зміни пароль точки доступу** в **Network** і вимкни
   **Show access point password on screen** у **Display → Splash screen**,
   коли екран у публічному місці.
6. **Зміни пароль SSH** або залиш SSH вимкненим. Якщо ввімкнеш його, картка
   попереджатиме, доки не зміниш стандартний пароль.
7. **Не вмикай термінал.** [Режим розробника](/docs/maintenance/developer-mode)
   може ввімкнути **Terminal**, який дає root-доступ до пристрою з браузера.
8. **Захисти віддалений доступ паролем.** З Tailscale чи WireGuard
   вебінтерфейс доступний і з тієї мережі, тож крок 1 ще важливіший.

<Admonition type="warning" title="Експортовані налаштування містять секрети">
  Експорт налаштувань містить паролі Wi-Fi, ключ потоку RTMP і паролі RTSP та
  SRT. Нікому не показуй цей файл.
</Admonition>

## Також варто знати

- **Оновлення підписані.** Пристрій встановлює лише пакет, підписаний
  ключем релізів YStreamer, — завантажений чи вивантажений вручну. Див.
  [оновлення](/docs/maintenance/updates).
- **Вхід діє 30 днів** у браузері. Новий пароль виводить із системи всі інші
  браузери.
- **Неправильні паролі сповільнюються**, тож підбір пароля вебінтерфейсу
  займає багато часу.
- **Забув пароль?** Див. [резервна копія та скидання](/docs/maintenance/backup-and-reset).
