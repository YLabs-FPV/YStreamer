Який вихід використовувати, залежить від того, що приймає відео:

| Програма                        | Вихід                             | Інструкція                                                   |
| ------------------------------- | --------------------------------- | ------------------------------------------------------------ |
| VLC, ffplay, ffmpeg             | RTSP (увімкнено за замовчуванням) | [VLC і ffplay](/docs/other-software/vlc)                     |
| OBS Studio                      | SRT або RTSP                      | [OBS Studio](/docs/other-software/obs)                       |
| vMix, OBS з DistroAV, TriCaster | NDI або OMT                       | [NDI та OMT](/docs/other-software/ndi-and-omt)               |
| QGroundControl, Mission Planner | UDP (RTP, порт 5600)              | [Наземні станції](/docs/other-software/ground-stations)      |
| YouTube, Twitch, Facebook       | RTMP                              | [Стрімінгові платформи](/docs/other-software/live-platforms) |

Налаштування кожного виходу описано в розділі [трансляція](/docs/using/streaming).
