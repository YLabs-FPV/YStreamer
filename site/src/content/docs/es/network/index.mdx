---
title: Red y acceso
description: Conectar el dispositivo a una red, llegar a él desde cualquier sitio y protegerlo.
order: 20
---

El dispositivo puede crear su propia red Wi-Fi, unirse a la tuya, usar
Ethernet o compartir la conexión de un móvil por USB. Si no se puede llegar a
él, vuelve a crear su propia red para que siempre puedas entrar.

Cuando esté en una red, pon una contraseña a la interfaz web. Para llegar a él
desde fuera de tu red, usa Tailscale o WireGuard.
