Qué salida usar depende de lo que recibe el vídeo:

| Software                        | Salida                      | Guía                                                          |
| ------------------------------- | --------------------------- | ------------------------------------------------------------- |
| VLC, ffplay, ffmpeg             | RTSP (activado por defecto) | [VLC y ffplay](/docs/other-software/vlc)                      |
| OBS Studio                      | SRT, o RTSP                 | [OBS Studio](/docs/other-software/obs)                        |
| QGroundControl, Mission Planner | UDP (RTP, puerto 5600)      | [Estaciones de tierra](/docs/other-software/ground-stations)  |
| YouTube, Twitch, Facebook       | RTMP                        | [Plataformas en directo](/docs/other-software/live-platforms) |

Los ajustes de cada salida se describen en [streaming](/docs/using/streaming).
